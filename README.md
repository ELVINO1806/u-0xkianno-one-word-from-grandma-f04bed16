## Entry

One word a grandma would text about AI: **SMARTALECK**.

Grandma doesn't say "large language model" — she says the machine is a
smart aleck: it always has an answer, it's a little too clever for its own
good, and she loves it anyway. Warm, slightly wrong, affectionate — exactly
the texting energy of a grandma meeting AI for the first time.

## Run

```sh
python3 main.py
```

The program writes exactly `SMARTALECK` (10 bytes, no trailing newline) to `/output/entry.txt`.
